# Overview

Chrome DevTools MCP — a Model Context Protocol (MCP) server that exposes Chrome DevTools functionality to MCP-compatible AI clients (e.g. Gemini, Claude, Cursor, Copilot). It lets agents drive a real Chrome browser, inspect the DOM, capture network/performance traces, and take screenshots.

See [README.md](README.md) for install (npx), supported MCP clients, configuration, and the list of available tools.
